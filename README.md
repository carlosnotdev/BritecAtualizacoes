# Comandas/Mesas Britec - Atualizacoes

Distribuicao oficial dos executaveis desktop e pacotes do servidor. O codigo-fonte e privado e nao esta neste repositorio.

[Baixar a versao mais recente](https://github.com/carlosnotdev/BritecAtualizacoes/releases/latest)

A partir da versao 0.0.3, o desktop consulta novas versoes no icone depois de Configuracao. Copie essa versao uma vez para cada terminal para habilitar o atualizador. O servidor e atualizado separadamente com o servico parado, preservando a configuracao.

Os releases incluem manifesto de atualizacao e hashes SHA-256. Nao incluem INI, credenciais, banco ou fotos de clientes.
